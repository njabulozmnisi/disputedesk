## Findings

- **F1 (informational):** `HEAD /scalar/` through the gateway returns 401, not the 405 that 5.5 criterion 5 says the Api gives. The route has no HEAD endpoint, so the fallback policy answers first. It is harmless, and `smoke.sh` uses GET.
- **F2 (informational):** the Scalar locations send no `Cache-Control`. The Scalar page and bundle are static and anonymous, so this is acceptable. `/openapi/v1.json` is also served without one. The story doesn't require it.
- **F3 (informational):** the story lists `at+jwt` as a possible `typ`, but real Zitadel access tokens carry `typ: JWT`. `ValidTypes` therefore stays unset and the actor mapping is the backstop, as the story's own fallback says. The builder's report should state this.
