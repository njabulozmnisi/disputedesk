## Four hops

Browser = Zitadel sign-in as seeded customer A in Playwright, through the gateway on :8080. Network = every request and OTLP export read from the browser. Trace store = Aspire Dashboard telemetry API (`/api/telemetry/traces?traceId=`). Database = `qa_readonly`. Events = the relay's producer span in the same trace.
