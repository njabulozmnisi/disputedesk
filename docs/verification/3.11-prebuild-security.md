Security (pre-build), base `b009f12`, package set as the human chose: `@opentelemetry/browser-instrumentation` 0.9.0 (`./experimental/fetch`), `@opentelemetry/sdk-trace` 3.0.0, `@opentelemetry/core` 3.0.0, `@opentelemetry/api` 1.10.0, and the OTLP exporter at 0.300.0. No high, no `[decision]`.

Already covered:
- **Gateway `/otlp/`** (`nginx.conf.template`): POST only (405 with `Allow`), 1 MB cap, `Cookie` and `Authorization` blanked, coarse per-IP zone.
- **CSP:** `connect-src 'self'` covers `/otlp/v1/traces` with no change.
- **Exports are never traced.** The browser transport calls `fetch.__original` under `suppressTracing` (`otlp-exporter-base` 0.300.0, `fetch-transport.mjs:41,52`), and `@opentelemetry/instrumentation` 0.223.0's shimmer sets `__original`.
- **No `eval` or storage:** the dists contain no `eval(`, `new Function(`, `localStorage`, `sessionStorage` or `document.cookie` (browser-instrumentation 0.9.0, instrumentation 0.223.0 ESM, sdk-trace and resources 3.0.0, otlp-exporter-base 0.300.0).
- **No zone.js** (pre-build review).

## Resolution

- T1: criterion 5 names `sanitizeUrl` (applied at span creation) and asserts `http.url` is absent.
- T2: criterion 5's exact attribute-key allow-list; criterion 1's source scan allowing only the `./experimental/fetch` subpath and `measureRequestSize` off; no resource detector.

- T6: Build facts pin every direct dependency exactly (`@opentelemetry/api` 1.10.0), record the dependency tree, and the builder confirms the Node hook packages stay out of the bundle.
- T7, T8: carried to story 7.6's Notes as production-path inputs.
