## Findings and the supervisor's check against the criteria

1. **High, accepted.** After any submit, react-hook-form's default `reValidateMode: 'onChange'` re-validates every keystroke; the conditionally rendered `ErrorSummary` remounts and its mount effect takes focus mid-typing (`OtpScreen.tsx:66-72`, `DetailsScreen.tsx:36-42`, `ErrorSummary.tsx:11-13`). Criterion 2: "the error summary … takes focus" on a press; criterion 4 cites "SC 3.2.2 *On Input*". No criterion asks for errors to update while typing.
2. **Medium, accepted.** Same cause: the first digit after a 422 replaces "You have 2 tries left." (criterion 5) with "Enter the 6-digit code."
3. **Medium, accepted, merged with the verifier's AC8 failure.** Criterion 8: "every state … empty, field errors, pending, wrong code, locked, rate limited with and without a wait, and the problem notice … passes the axe-core check"; "in every error state (client validation, a server 400, 422, 409 and 429) the rendered text holds none of the typed values".
4. **Low, accepted with the verifier's standards point.** `retryAfter.ts` reads only IMF-fixdate; RFC 9110 §5.6.7 asks recipients to accept all three HTTP-date forms. Nothing in the system sends a date (the limiter sends 900, the gateway 1), so the plainest correct course is a marked shortcut.
5. **Low, deferred to the refactor sweep.** `validationFields` is the third copy of the `errors` cast (`ReviewScreen.tsx:47`, `WithdrawDialog.tsx:49`); the story's Boundaries leave those screens unchanged.
6. **Nits, accepted:** drop the redundant `instanceof ApiError` at `OtpScreen.tsx:86`; assert heading focus after "Start again" (criterion 3); assert the header on `/link/otp` too (criterion 8). The duplicate `z.config({ jitless: true })` goes to the sweep.

Verifier AC1, accepted in part: criterion 1 says "no history entry's state, URL or `location.hash` holds a submitted value, as `ReviewScreen.test.tsx` checks", and the test checks only the current entry. Its "cached query data" point is not accepted: criterion 1 names the mutation cache, which is tested.
