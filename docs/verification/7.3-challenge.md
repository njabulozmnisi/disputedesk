## Pre-mortem

[story] CI passes without running the promised journeys. Playwright discovers `e2e/tests/`, while stories 7.1 and 7.2 propose `e2e/journeys/`; a fresh stack also does not isolate tests that each consume customer D or change seeded disputes.

## Simplest design

[story] Use one `e2e` job on PRs and main pushes: `docker compose up --build --wait`, install the pinned E2E dependencies and Playwright browser, run the discovered suite, then run the ZAP baseline against the gateway with an explicit rules file. Fail on failed tests or untriaged findings; collect diagnostics and tear down the stack even on failure. No second test framework, reset endpoint or custom scanner is needed.

[story] Use one main-push-only `publish` job, dependent on the CI jobs, with job-scoped `packages: write`. Build the five existing Dockerfile targets, authenticate with `GITHUB_TOKEN`, and push immutable SHA-derived tags—no `latest` tag or custom publishing mechanism.

## Assumptions

[story] The specified ZAP target is the public gateway and the scan is unauthenticated. The story names neither target nor authentication; the existing QA baseline targets `http://host.docker.internal:8080`.

[decision] Story 7.3 owns publishing, but architecture **AD-32 explicitly assigns `publish` to the AWS story**. Decide which story owns it; this changes an architecture decision, not just wording in 7.3.

## Standards

[story] No invented mechanism is necessary. Use the documented [Compose `up --wait`](https://docs.docker.com/reference/cli/docker/compose/up/), [Playwright CI setup](https://playwright.dev/docs/ci), [ZAP baseline rules and exit behavior](https://www.zaproxy.org/docs/docker/baseline-scan/), and [GitHub’s container-registry publishing pattern](https://docs.github.com/en/actions/tutorials/publish-packages/publish-docker-images). Do not substitute a home-grown finding parser for ZAP’s rules and exit status.

Sofia, 2026-10-30. The `[decision]` point is settled by the human decision above (7.3's Description, criteria 4 and 5, and Notes; AD-32 amended). `[story]` points folded:

- Journeys not discovered and shared state: the `e2e` job runs `npm run journeys`, story 7.1's `journeys` project under `e2e/tests/journeys/`, on the runner's fresh stack; the `regression` project is not part of this job (criterion 1).
