## Findings

- **L1, low** `e2e/tests/linking-screens.spec.ts:220`. `borderTopWidth >= 1` is true for every cell, active or not, so it proves nothing about focus. `boxShadow.includes('inset')` proves an inset shadow exists, but not that it is at least 1px wide or visible: `inset-ring-0` or `inset-ring-transparent` passes, and so does a `ring-inset` halo. The check fails when the ring is removed, and it is no weaker than the generic branch's `boxShadow !== 'none'`, so the focus criterion is not left unproved. It does not prove the 2px edge the comment describes. Fix: match the inset part, for example `/(rgba?\([^)]*\)) 0px 0px 0px (\d+(?:\.\d+)?)px inset/`, and require a spread of at least 1 and a colour that is not `rgba(0, 0, 0, 0)` (or equal to `borderTopColor`). Drop or replace the border clause.
- **L2, low** `e2e/run-regression.sh:41-45`. The comment says "a host port the stack publishes", but only 4317 and 4318 are checked. The stack also publishes 5433, 19092, 8025, 18888 and the fixed 8080 (`docker-compose.yml:42-306`), and a taken 8080 (common) still ends each group with a docker error. Fix: either list every published port with its override in the loop (the same loop, one line each), or narrow the comment to the OTLP ports.
- **L3, low** `e2e/run-regression.sh:66`. A taken port does not free itself between groups, so the run repeats the same line seven times. `require_free_ports || exit 1` stops at the first, with one message. The stack is already down at that point, so skipping the final `stop` is harmless. Optional; the current behaviour is acceptable.
- **L4, low** `e2e/run-regression.sh:58, 68`. When `up` fails, `e2e/test-results` still holds the previous group's run. If that group failed, its `error-context.md` files print again under the new group's header, which looks like a test failure in a group whose tests never ran. Fix: print the snapshots only on the test-failure path (move the `find` behind a parameter, or call it only from line 73), or note in the header that the snapshots belong to the last Playwright run.
