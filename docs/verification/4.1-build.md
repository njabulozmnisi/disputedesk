**What was built**

- **Raw SQL:** only the lock call and `SELECT 1`. Head rows are chosen with EF: due Pending rows (`NextAttemptAtUtc <= @now`) with no earlier unsent version of the same dispute. They are sent one at a time, and each is marked Sent with the batch's single clock read only after its delivery report.

**Deviations from the story you should look at**
- **"The other host's exporter records no producer span" can't be tested as written.** ActivitySource listeners are process-wide, so both in-process hosts' exporters see every span. The leadership test instead checks that exactly one host logs that it holds the lock, and that each row has one record and one producer span.
- **Heartbeat path:** Sonar S5443 rejected a hard-coded `/tmp`, so I used `Path.Combine(Path.GetTempPath(), "heartbeat-relay")`. That is `/tmp/heartbeat-relay` in the container but would move if anyone set `TMPDIR` there.
