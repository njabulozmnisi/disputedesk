## Fixes
1. **One `h1` element (medium).**
   - `DisputeDetailScreen` now renders a single h1 at one fixed position across loading, failure, not-found and loaded. It reads "Dispute" until the data arrives, then the transaction description, or "We can't find that dispute" for a 404.
   - `usePageHeading` is called once, so 3.7's first-heading ref sees one element. The three per-state components and the separate `NotFoundPage` use on the API 404 are gone from this screen.
   - **Test first:** I added 3 direct-load first-Tab tests in `routing.test.tsx`, under StrictMode: loaded, a 500 failure, and an API 404. All three failed before the change (focus landed on the Withdraw button, and the other two also missed the skip link).
   - They pass after the change.
   - A unit test also asserts the loading h1 is the same element as the loaded one.
2. **Timeline promise line.** It is now a `<p>` after the `</ol>`. The test asserts its tag is P, that it is not inside an `li`, that it follows the `ol`, and that the list has one item.
3. **Card/Account row.** It uses a local `MaskedNumberValue`: label "Card" or "Account", value `492345•• •••• 3456`, plus screen-reader text `ending 3456`. The test asserts no repeated "Card 492345".
4. **Transactions invalidation.** Both the 200 test and the 409 `withdrawn` test seed the disputes and transactions infinite keys and assert `isInvalidated`.
5. **Reason label.** It uses `Object.hasOwn(reasonCopy, dispute.reason)` instead of the `Partial` cast.
6. **Nits.**
   - The resolved notice is the literal "This dispute is now Resolved. It can't be withdrawn."
   - The gone flag is now `goneDisputeId`, compared with the current `disputeId`.
   - `BackToDisputes` is inlined.
   - Only the Timeline `section` is labelled, and the list is found as a region plus list in tests.
   - The timeline key is the index.
   - The old test at line 287 is renamed "has no accessibility violations on a rejected dispute". The old one at line 406 is renamed "ends an open dispute with the promise to update, after the list and not as an entry in it".
   - **Unrequested:** `Timeline` now works out `isOpen` itself, so the `isOpen` prop is removed.
