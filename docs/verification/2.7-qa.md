- All responses were `application/problem+json`. core-banking was stopped and started again; it is healthy afterwards.
- Every `type` URL was the exact resolvable GitHub URL. No `tag:` value appeared.
- Each slug has `docs/problems/<slug>.md`, and the page's `Status:` line equals the response status in all six cases.
- Slug catalogue sweep: every slug string in `Contracts/Problems/*.cs` has a page (12 slugs checked; the others in docs/problems are the base-set pages).

- The only production code diff is `ProblemType.cs` (`Prefix` and `For`); title, status, detail and errors code paths are untouched.
- Four hops: browser and database not applicable (API-level, no SPA or write). Network checked above. Events: none emitted by these paths.
