**How the tests work**
- The test imports the real `main.tsx` afresh each time, using `vi.resetModules` and `vi.stubEnv`.
- A `vi.mock` wraps the real `startTracing` in a spy.
- `setup.ts` starts tracing before any test file's mock exists. Without a reset, the no-op assertions would pass whatever the code did. So `startApp` first calls `trace.disable()`, `context.disable()` and `propagation.disable()`, so only the app start under test can register tracing.
