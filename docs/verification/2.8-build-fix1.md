### Fix items

1. **Dispute audit counts.** After 3.8, `DisputesApi.CountRowsAsync` counts only audit rows with a dispute action. So the temporary `SignInEntriesOnly(n)` helper is gone and the four assertions are back to their original `RowCounts.None`. Nothing is loosened.
2. **`ApiReferenceTests`.** The Production 404 rows now sign the caller in and keep their assertion. A new `ApiReference_ProductionAnonymous_Returns401` covers `/scalar` and `/openapi/v1.json`. The supervisor needs to add this file to the story's Touches list, since I can't write under `docs/`.
3. **`id_token_hint`.** The hand-set hint and its `IdTokenParameter` are removed; the OIDC handler reads the hint itself from the cookie scheme. The end-session test still asserts `id_token_hint` equals the issued ID token. The old break, which could never fail, is replaced by one that does: setting `IdTokenHint = null` in the sign-out event makes the test fail.
4. **Smoke check.** Passed after the 3.8 rebase (details below).
5. **Report location.** This message only.
6. **Intermittent stub start-up failure.** I confirmed the root cause in the `WebApplicationFactory` and `DeferredHostBuilder` source for 10.0:
   - `UseKestrel(int)` makes `CreateHost` rewrite the server addresses after `Build()` and before `Start()`.
   - With a top-level-statements entry point, the app's own `RunAsync` thread starts Kestrel at the same time, on the default `localhost:5000`. If that thread wins, the address list is read-only and the rewrite throws the CI exception.
   - **Fix:** put the port in Kestrel's own options instead, `UseKestrel(k => k.Listen(IPAddress.Loopback, 0))`, so nothing rewrites the addresses. It is applied in `CoreBankingStubFactory` and in the one other `UseKestrel(0)` call, in `SecurityHeadersTests`.
   - **Test:** `CoreBankingStubStartTests` forces the losing order every time by waiting for the app to start before `Build()` returns. With `UseKestrel(0)` restored it fails with the exact CI exception; with the fix it passes.
7. **No `using X = ...;` aliases** in the diff (checked by grep, and `UsingAliasRulesTests` passes).
