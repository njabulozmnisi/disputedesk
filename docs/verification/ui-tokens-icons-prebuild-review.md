Checked on 2026-11-08 in the npm registry and the published tarball, which was unpacked in a scratch folder and not installed:
- `lucide-react` 1.70.0 is the `latest` tag, published 2026-11-06. Maintainer `ericfennis`, repository `github.com/lucide-icons/lucide`, ISC licence, no runtime dependencies, peer `react ^16.5.1 || … || ^19.0.0`. 130,919,011 downloads in the week 2026-11-01 to 11-07.
- `Send`, `Search`, `Flag`, `Check`, `X`, `Undo2`, `List` and `Info` all exist.
- `createLucideIcon(iconName: string, iconNode: LucideIconNode[], aliases?: string[]): LucideIcon` is exported and typed. Every built-in icon is made with it.
- An icon gets `aria-hidden="true"` by default unless it is given an `aria-*`, `role` or `title` prop, or children. Docs: <https://lucide.dev/guide/react/advanced/accessibility>.
- Default attributes: `width`/`height` 24, `stroke="currentColor"`, `stroke-width` 2. The class is `lucide lucide-<kebab-name>`, so `createLucideIcon('SearchPriority', …)` gives `lucide-search-priority` and the display name `SearchPriority`.
- Lucide 1.70's `Search` is `circle r=8` plus `m21 21-4.34-4.34`. The mockups draw `r=7` plus `m20 20-3.5-3.5`.

CSP: Lucide renders inline SVG with presentation attributes only (no `style`, no fetch), so CSP needs no change. No security findings.
