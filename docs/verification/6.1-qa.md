## Standards

- RFC 9110: 202 with no body, 401/403/400 split by check order; `Cache-Control: no-store` on every response, 202 and problems alike.
- RFC 9457: 400 and 401/403 are `application/problem+json` with the catalogue `type` and a `traceId`.
- OWASP Forgot Password Cheat Sheet: identical status, headers and body across no-match, matching and linked details; response timing and size were not measured by a timing harness here (the security agent owns it).
- OWASP Logging Cheat Sheet / POPIA: no personal data in logs, spans or tables.
- Gateway: the coarse `limit_req` (10 requests a second, burst 20, 429) trips a loop of start calls; the e2e spec paces its calls by 150 ms. This is the gateway limit named in the story, not a finding.
