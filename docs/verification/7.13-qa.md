## Standards

- RFC 6265bis: transient cookies are `Secure`, `SameSite=None` (needed for the cross-site `form_post` callback), `HttpOnly`, no `Domain`, `Path=/`; deletions use an expired date with the same attributes. The `__Host-` prefix needs `Secure`, `Path=/` and no `Domain`, all met, so the AWS names will be accepted. No deviation.
- RFC 9110 and 9457: 409, 422 and 404 answers are problem details with the `type` slugs asserted by the existing specs; unchanged.
- Observation, unchanged by this story: `Path=/` sends the transient cookies on every request for their 15-minute life (story Notes, accepted).
