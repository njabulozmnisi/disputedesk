## 1. forbidOnly (criterion 1, QA-owned part)

Finding: `e2e/playwright.config.ts` at 21040a8 did not set `forbidOnly`, although the ci.yml comment says it does. With a throwaway `test.only` on uj-1 and the unchanged config, `CI=1 npx playwright test --list --project=journeys` exited 0 and listed all 5 tests, so a committed `test.only` would not have failed CI.

Fix (QA owns e2e/): added to `e2e/playwright.config.ts`
`forbidOnly: !!process.env.CI,` (Playwright `TestConfig.forbidOnly`, https://playwright.dev/docs/api/class-testconfig#test-config-forbid-only). `retries` is not set, so it stays 0.

Proof with the same throwaway `test.only` on `tests/journeys/uj-1.spec.ts:42`:

| Command | Result |
|---|---|
| `CI=1 npx playwright test --list --project=journeys` | exit 1, `Error: item focused with '.only' is not allowed due to the 'forbidOnly' option ... journeys/uj-1.spec.ts UJ-1 ...`, 0 tests listed |
| same, `CI` unset | exit 0, 5 tests listed |

The spec was restored from a copy; `git diff -- e2e/tests` is empty.
