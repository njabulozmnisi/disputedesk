# Pre-build security read: 5.4

Security (pre-build), base `5cb8b62` (the `Seeder`, `SeedRegistration`, `DatabaseMigrator`, `AppDbContext`). No high, no `[decision]`; both 2026-10-30 decisions are settled. Already covered:
- `Seed:Enabled` defaults to false in `SeedOptions`, is absent from `appsettings.json`, and is set only in Compose; `Seed:FixturesPath` is required when it is on (`ValidateOnStart`).
- `Dispute` setters are private, and the commit override refuses a dispute that is added or modified with no pending stored event, so a status cannot be set directly.
- The seeder runs inside EF's migration lock, and `SeededLinksTests` already covers a second run, two instances at once, the synchronous path and seeding switched off, for links.
- `OwnershipRulesTests` (5.1) refuses any bypass under `Infrastructure/Seeding/`.
