Standards to cite in the story:
- JwtBearer: Microsoft Learn, *Configure JWT bearer authentication in ASP.NET Core*.
- RFC 6750 §3 (Bearer challenge), RFC 7519 (JWT claims), RFC 6749 §4.4 (client credentials).
- OpenAPI Security Scheme Object, through Microsoft Learn's document and operation transformers.
- Microsoft Learn, *Policy-based authorization*.
- EF Core, *Global query filters* (named filters).
- OWASP Logging Cheat Sheet.

Nothing in the design is home-grown where a standard exists.
