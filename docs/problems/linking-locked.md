# Linking locked

- Type: `https://github.com/njabulozmnisi/disputedesk/blob/main/docs/problems/linking-locked.md`
- Status: 409 (AD-3 `Conflict`: the challenge is locked; RFC 9110 §15.5.10)

## When it happens

Too many wrong codes locked the linking challenge.

## What a client should do

Do not retry now. Tell the person when they can start linking again.
