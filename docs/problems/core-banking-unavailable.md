# Core banking unavailable

- Type: `https://github.com/njabulozmnisi/disputedesk/blob/main/docs/problems/core-banking-unavailable.md`
- Status: 503

## When it happens

The bank's core banking system did not answer in time after the retries, or answered with data DisputeDesk cannot trust.

## What a client should do

Retry later. Disputes already raised stay available.
