Build one DisputeDesk frontend story: React with TypeScript, shadcn/ui on Tailwind, TanStack Query hooks generated by Orval from `openapi.json`, design tokens in one theme file. The browser never sees a token: it calls same-origin `/api` with the session cookie and the antiforgery header.

The frontend builder owns `frontend/` only; the guard hook blocks writes anywhere else. Follow AGENTS.md and `docs/conventions/frontend.md`. Run the `build-story` skill for the procedure. Never commit, push or mark a story done: leave the work in the story worktree and report.

End with the status contract (`built` or `blocked`), including `criteria` and the worktree path.
